# 写真カプセル＋ 順次ダウンローダー

[写真カプセル+ Web](https://webapp.photo-capsule-puls.net/) で合言葉を受け取るときに使う Tampermonkey 用スクリプトです。サイトは標準で全ファイルを同時に取得して一斉に保存しますが、このスクリプトはそれをやめて、自分で選んだフォルダ（またはダウンロードフォルダ）へ少しずつ順番に保存します。

- ファイル数が多くても、動画が大きくても、途中で落ちにくい
- URLの有効期限（10分）が切れる前に、自動で取り直して続ける
- 中断しても、続きから再開できる
- 掲示板でコピーした合言葉を、パネルのボタン1つで受け取れる

> 非公式のスクリプトです。写真カプセル+ の運営とは関係ありません。サイトの仕様が変わると動かなくなることがあります。

## 動作環境

- PC版の **Chrome** または **Edge**（「フォルダに書き込む」方式で使う機能が、Firefox やスマホにはないため）
- [Tampermonkey](https://www.tampermonkey.net/)
- 写真カプセル+ Web にログインしていること

## インストール

1. Tampermonkey を入れた状態で、次のリンクを開く
   **[photocapsule-downloader.user.js をインストール](https://raw.githubusercontent.com/Hoyomaru/photocapsule-downloader/main/photocapsule-downloader.user.js)**
2. Tampermonkey のインストール画面で「インストール」を押す

この方法で入れると、新しい版が出たときに Tampermonkey が自動で更新します。

旧版（v1.x 以前）を入れている場合は、無効にするか削除してください。一緒に動くと、ファイル名がおかしくなる原因になります。

## 保存方式を選ぶ

パネルの上部で、次の2つから選べます（選んだ方式は記憶されます。保存中は切り替えられないので、一時停止してから切り替えてください）。

| 方式 | 保存先 | 向いている場合 |
|---|---|---|
| **ダウンロードとして保存** | `ダウンロード/写真カプセル/合言葉名/` | 書き込み許可の確認を毎回出したくない |
| **フォルダに書き込む** | 自分で選んだフォルダ | ファイル名を変える拡張機能を入れている、好きな場所に保存したい |

### ダウンロードとして保存

- Tampermonkey の機能でダウンロードするので、書き込み許可の確認は出ません
- ブラウザのダウンロード機能を使うため、ファイル名を変える拡張機能を入れているとファイル名が変わることがあります
- Chrome の設定で「ダウンロード前に各ファイルの保存場所を確認する」がオンだと、ファイルごとに保存画面が出ます。オフにしてください
- フォルダに分かれずに保存される場合や、「保存を許されていません」と出る場合は、Tampermonkey の設定（設定モードを「上級者」にする）の「ダウンロード」で次を確認してください
  - ダウンロードモード：**ブラウザ API**
  - ホワイトリストに登録されたファイル拡張子：jpg・png・mp4・mov・heic など、受け取るファイルの拡張子が入っているか

### フォルダに書き込む（初回：保存先フォルダを選ぶ）

- サイトを開くと右下にパネルが出るので、**「保存先を選ぶ」** を押してフォルダを選ぶ
- Chrome が「このフォルダへの書き込みを許可しますか」と聞いてくるので許可する。**「毎回許可する」** が出るブラウザならそれを選べば次回から聞かれなくなる。出ない場合は毎回聞かれるので、気になるなら「ダウンロードとして保存」を使う
- **ダウンロードフォルダそのものは選べません**（Chrome の制限で「システムファイルが含まれているため開けません」と出ます）。選択画面の「新しいフォルダー」で中にフォルダ（例: 写真カプセル）を作り、それを選んでください

## 使い方

- 掲示板などで合言葉をコピーし、パネルの **「貼り付けて受け取る」** を押す。合言葉がサイトの入力欄に入り、「受け取る」まで自動で押される
  - 初めて押したときは、Chrome が「クリップボードの読み取りを許可しますか」と聞いてくるので許可する
  - トップページ以外（受信の完了画面など）で押した場合は、トップページへ移ってから受け取る
  - コピーした文字の前後の空白・改行・かっこ（「」など）は取り除く。合言葉が見つからないときはパネルに表示する
  - コインが必要な合言葉の確認など、受け取りの手順はサイトのものをそのまま使う
- いつも通り合言葉を手で入れて「受け取る」を押してもよい。どちらでも、パネルの中で順番に保存が進む
- 保存先：`選んだフォルダ/合言葉名/合言葉名_01.jpg` …（ダウンロード方式では `ダウンロード/写真カプセル/合言葉名/合言葉名_01.jpg` …）
- フォルダ方式で書き込みの許可が切れているときは、パネルの **「許可する」** を押すと保存が始まる（Chrome の仕様で、クリックしないと許可を出せない）
  - 許可とは関係ない理由（ファイルが他のアプリで開かれている、など）で止まったときは「許可する」は出ず、パネルに原因が表示される。原因を取り除いてから「再開」を押す

## パネル

- サイトを開くと、いつも右下に表示される
- **貼り付けて受け取る**：コピーした合言葉で受け取る（保存中は表示しない）
- 表示内容：保存先、合言葉名と状態（保存中・一時停止・完了・一部失敗・要対応）、進み具合（％、件数、容量）、速度と残り時間
- **一覧**：ファイルごとの状態を番号付きのタイルで表示する。水色＝保存済み、輪＝保存中（輪が進み具合）、黄＝再試行待ち、赤＝失敗。**赤いタイルを押すと、そのファイルだけ再試行**する
- **同時**：同時に保存する本数（1〜6本、初期値3本）
- **一時停止 / 再開**：一時停止しても、実行中のファイルは最後まで保存する
- **失敗分を再試行**：失敗したファイルをまとめて取り直す
- **保存方式**：「ダウンロードとして保存」と「フォルダに書き込む」を切り替える
- **変更**：保存先フォルダを選び直す（フォルダ方式のみ）
- **移動**：青い見出しの部分をドラッグすると、好きな位置に動かせる
- **最小化（－）**：右下の丸いバッジになり、％や状態だけを表示する。押すと元に戻る
- **×**：パネルを閉じる（保存は続く）。Tampermonkey のメニュー「進み具合のパネルを表示」で再表示できる
- 位置・最小化・一覧の開閉・同時数は記憶される。色は Windows や Chrome のダークモードに合わせて自動で切り替わる

## 自動でやってくれること

- **URLの期限切れ対策**：URLの有効期限が切れる1分前に、新しいURLを自動で取り直して続ける
  - **コインが必要な合言葉では取り直しません**（コインを消費する可能性があるため）。期限が切れたら止まるので、合言葉を入れ直せば未保存の分から続きます
- **再開**：ページを閉じたり再読み込みしたりしても、サイトを開くとパネルに「途中で止まった受信」が出る。「再開」を押せば、合言葉を入れ直さずに続きから保存する
  - すべて保存し終わって 30 日たった受信の記録は、自動で消す
- **離れる前の確認**：保存中にタブを閉じたり別のページへ移ろうとしたりすると、ブラウザが確認を出す（続きから再開はできるが、保存中だったファイルは最初から取り直しになるため）
- **重複防止**：フォルダ方式では、保存先に同じ名前・同じ大きさのファイルが既にあれば取得を飛ばす。ダウンロード方式では、同じ名前のファイルを上書きする（「(1)」付きの重複を作らない）
- **中途半端なファイルを残さない**：フォルダ方式では一時ファイルに書き込み、最後まで受け取れたときだけ正式な名前で置かれる

## 困ったとき

- **サイトを開いてもパネルが出ない**
  - Tampermonkey のダッシュボードで、このスクリプトが有効になっているか、版が最新（2.4.3 以降）かを確認する。古ければ「更新を確認」を押してから、ページを開き直す
  - それでも出ないときは、Tampermonkey のメニュー「進み具合のパネルを表示」を押す
- **「前回のフォルダを Chrome で確認できなかったので、選び直してください」と出る**
  - Chrome が、前回選んだフォルダの許可の問い合わせに答えないことがあります。「保存先を選ぶ」で、もう一度フォルダを選んでください（同じフォルダでかまいません）
  - 何度選び直しても出る場合は、保存方式を「ダウンロードとして保存」にすると、フォルダの許可を使わずに保存できます
- **「許可する」を押しても何も出ない**
  - 2.4.0 以前の不具合です。最新版に更新してください

## 仕組み

サイトの受信は次の流れで動いています（2026年11月時点）。

1. `/v1/watchwords/search.json` で合言葉から合言葉IDを得る
2. `/v1/watchwords/download.json` でファイル一覧（署名付きURL、サイズ、種類）を得る
3. 全URLを同時に取得し、まとめて保存する

このスクリプトは 2 の応答を読み取り、3 の一斉取得は止めます。そのうえで各ファイルを少しずつ順番に保存します。

- フォルダ方式：自分で取得し、[File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_API) で選んだフォルダへ書き込む。ブラウザのダウンロード機能を使わないので、他の拡張機能にファイル名を変えられることもない
- ダウンロード方式：Tampermonkey の `GM_download` でダウンロードフォルダへ保存する

## パネルを試す

`preview/` には、サイトとの通信と保存を偽物に差し替えて、パネルだけを動かせるページが入っています。

```bash
node preview/serve.js
```

起動したら http://localhost:5317 を開いてください。実際にはファイルを保存しません。
