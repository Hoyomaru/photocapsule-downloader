# 写真カプセル＋ 順次ダウンローダー

[写真カプセル+ Web](https://webapp.photo-capsule-puls.net/) で合言葉を受け取るときに使う Tampermonkey 用スクリプトです。サイトは標準で全ファイルを同時に取得して一斉に保存しますが、このスクリプトはそれをやめて、自分で選んだフォルダへ少しずつ順番に書き込みます。

- ファイル数が多くても、動画が大きくても、途中で落ちにくい
- URLの有効期限（10分）が切れる前に、自動で取り直して続ける
- 中断しても、続きから再開できる

> 非公式のスクリプトです。写真カプセル+ の運営とは関係ありません。サイトの仕様が変わると動かなくなることがあります。

## 動作環境

- PC版の **Chrome** または **Edge**（フォルダへ直接書き込む機能を使うため。Firefox やスマホでは動きません）
- [Tampermonkey](https://www.tampermonkey.net/)
- 写真カプセル+ Web にログインしていること

## インストール

1. Tampermonkey を入れた状態で、次のリンクを開く
   **[photocapsule-downloader.user.js をインストール](https://raw.githubusercontent.com/Hoyomaru/photocapsule-downloader/main/photocapsule-downloader.user.js)**
2. Tampermonkey のインストール画面で「インストール」を押す

この方法で入れると、新しい版が出たときに Tampermonkey が自動で更新します。

旧版（v1.x 以前）を入れている場合は、無効にするか削除してください。一緒に動くと、ファイル名がおかしくなる原因になります。

## 初回：保存先フォルダを選ぶ

- サイトを開くと右下にパネルが出るので、**「保存先を選ぶ」** を押してフォルダを選ぶ
- Chrome が「このフォルダへの書き込みを許可しますか」と聞いてくるので許可する。**「毎回許可する」** を選べば、次回から聞かれなくなる
- **ダウンロードフォルダそのものは選べません**（Chrome の制限で「システムファイルが含まれているため開けません」と出ます）。選択画面の「新しいフォルダー」で中にフォルダ（例: 写真カプセル）を作り、それを選んでください

## 使い方

- いつも通り合言葉を入れて「受け取る」を押すと、パネルの中で順番に保存が進む
- 保存先：`選んだフォルダ/合言葉名/合言葉名_01.jpg` …
- 書き込みの許可が切れているときは、パネルの **「許可する」** を押すと保存が始まる（Chrome の仕様で、クリックしないと許可を出せない）

## パネル

- 表示内容：保存先、合言葉名と状態（保存中・一時停止・完了・一部失敗・要対応）、進み具合（％、件数、容量）、速度と残り時間
- **一覧**：ファイルごとの状態を番号付きのタイルで表示する。水色＝保存済み、輪＝保存中（輪が進み具合）、黄＝再試行待ち、赤＝失敗。**赤いタイルを押すと、そのファイルだけ再試行**する
- **同時**：同時に保存する本数（1〜6本、初期値3本）
- **一時停止 / 再開**：一時停止しても、実行中のファイルは最後まで保存する
- **失敗分を再試行**：失敗したファイルをまとめて取り直す
- **変更**：保存先フォルダを選び直す
- **移動**：青い見出しの部分をドラッグすると、好きな位置に動かせる
- **最小化（－）**：右下の丸いバッジになり、％や状態だけを表示する。押すと元に戻る
- **×**：パネルを閉じる（保存は続く）。Tampermonkey のメニュー「進み具合のパネルを表示」で再表示できる
- 位置・最小化・一覧の開閉・同時数は記憶される。色は Windows や Chrome のダークモードに合わせて自動で切り替わる

## 自動でやってくれること

- **URLの期限切れ対策**：URLの有効期限が切れる1分前に、新しいURLを自動で取り直して続ける
  - **コインが必要な合言葉では取り直しません**（コインを消費する可能性があるため）。期限が切れたら止まるので、合言葉を入れ直せば未保存の分から続きます
- **再開**：ページを閉じたり再読み込みしたりしても、サイトを開くとパネルに「途中で止まった受信」が出る。「再開」を押せば、合言葉を入れ直さずに続きから保存する
- **重複防止**：保存先に同じ名前・同じ大きさのファイルが既にあれば、取得を飛ばす
- **中途半端なファイルを残さない**：書き込みは一時ファイルに行い、最後まで受け取れたときだけ正式な名前で置かれる

## 仕組み

サイトの受信は次の流れで動いています（2026年11月時点）。

1. `/v1/watchwords/search.json` で合言葉から合言葉IDを得る
2. `/v1/watchwords/download.json` でファイル一覧（署名付きURL、サイズ、種類）を得る
3. 全URLを同時に取得し、まとめて保存する

このスクリプトは 2 の応答を読み取り、3 の一斉取得は止めます。そのうえで各ファイルを自分で取得し、[File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_API) で選んだフォルダへ少しずつ書き込みます。ブラウザのダウンロード機能を使わないので、他の拡張機能にファイル名を変えられることもありません。

## パネルを試す

`preview/` には、サイトとの通信とフォルダへの書き込みを偽物に差し替えて、パネルだけを動かせるページが入っています。

```bash
node preview/serve.js
```

起動したら http://localhost:5317 を開いてください。実際にはファイルを保存しません。
